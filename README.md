# Postroom releases

Compiled downloads of Postroom, a Mac app for planning and writing posts.

- Download the latest version from the [Releases](../../releases/latest) page: unzip it and move `Postroom.app` to Applications.
- The app checks this page for new versions by itself. You can turn that off in Settings → Updates.
- Each download is signed, and the app verifies an update before installing it.

This repository holds release downloads only.
